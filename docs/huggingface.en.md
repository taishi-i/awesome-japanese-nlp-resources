## Models
### text-generation
 * [japanese-gpt-neox-small](https://huggingface.co/rinna/japanese-gpt-neox-small) - 📥 656k / ⭐ 15 / A 12‑layer, 768‑hidden Japanese GPT‑NeoX model trained on CC‑100, C4, and Wikipedia, compatible with Huggingface, with an optional toy prefix‑tuning weight that forces each sentence to end with a smiling‑face emoji.
 * [Spark-X2.5-4B-Heretic-jp-gguf](https://huggingface.co/soyaakinohara/Spark-X2.5-4B-Heretic-jp-gguf) - 📥 589k / ⭐ 22 / Japanese‑adapted Spark‑X2.5‑4B model (Heretic JP) with refusal attenuation, pretraining, instruction tuning and tool‑calling repair, available in GGUF quantizations from BF16 to Q4_K_M (~2.5 GiB), usable via llama.cpp for 1,048,576‑token context.
 * [llm-jp-4-33b-thinking-gguf](https://huggingface.co/llm-jp/llm-jp-4-33b-thinking-gguf) - 📥 271k / ⭐ 11 / LLM‑jp‑4‑33b‑thinking‑gguf is a 33 B Japanese language model from the National Institute of Informatics, pre‑trained with SFT and DPO (no RL), available for llama.cpp via an LLM‑jp fork, and includes detailed usage instructions in its cookbook.
 * [llm-jp-4.1-8b-thinking](https://huggingface.co/llm-jp/llm-jp-4.1-8b-thinking) - 📥 80k / ⭐ 18 / LLM‑jp‑4.1‑8b‑thinking is a 33 B transformer language model from NII’s LLM R&D Center, pre‑trained with mid‑training only and aligned via SFT/DPO (no RL), designed for Japanese NLP tasks and documented in a cookbook and technical blog.
 * [llm-jp-3-150m](https://huggingface.co/llm-jp/llm-jp-3-150m) - 📥 75k / ⭐ 9 / LLM‑jp‑3‑150m—a 150‑M‑parameter Japanese language model from the National Institute of Informatics’ LLM R&D Center—is distributed in Hugging Face Transformers format, requiring torch ≥ 2.3.0, transformers ≥ 4.40.1, accelerate ≥ 0.29.3, flash‑attn ≥ 2.5.8, and was pretrained on Japanese Wikipedia, Common Crawl, WARP/PDF, WARP/HTML, and Kaken data using a unigram byte‑fallback tokenizer.
 * [llm-jp-4-8b-instruct](https://huggingface.co/llm-jp/llm-jp-4-8b-instruct) - 📥 49k / ⭐ 16 / llm‑jp‑4‑8b‑instruct is a 4.1 B‑parameter Japanese LLM from NII’s LLM‑jp‑4 series, pretrained on large corpora and then fine‑tuned solely with supervised instruction data (no DPO/REINFORCE) and accompanied by cookbook‑style usage guides and a byte‑fallback unigram tokenizer.
 * [sarashina2.2-3b-instruct-v0.1](https://huggingface.co/sbintuitions/sarashina2.2-3b-instruct-v0.1) - 📥 16k / ⭐ 39 / Offers an autoregressive Japanese language model (sarashina2.2‑3B‑instruct‑v0.1) from SB Intuitions, benchmarked against other models, with example usage scripts and a note that safety training is limited.
 * [llm-jp-4-8b-base](https://huggingface.co/llm-jp/llm-jp-4-8b-base) - 📥 11k / ⭐ 8 / A repository that hosts the 8.6 B‑parameter llm‑jp‑4‑8b‑base transformer from the National Institute of Informatics’ LLM R&D Center, trained with pre‑training and mid‑training followed by supervised fine‑tuning and direct preference optimization (no reinforcement learning), and provides a PyTorch‑transformers usage guide.
 * [Llama-3-Swallow-8B-Instruct-v0.1](https://huggingface.co/tokyotech-llm/Llama-3-Swallow-8B-Instruct-v0.1) - 📥 9k / ⭐ 21 / Llama3 Swallow is a Japanese‑enhanced Meta Llama 3 family released July 1 2024, offering 8B and 70B variants in Instruct and chat forms fine‑tuned with SFT and Chat Vector on Megatron‑LM, and benchmarked on key Japanese NLP tasks.

 * [llm-jp-4.1-32b-a3b-thinking-gguf](https://huggingface.co/llm-jp/llm-jp-4.1-32b-a3b-thinking-gguf) - 📥 9k / ⭐ 9 / LLM‑jp‑4.1‑32b‑a3b‑thinking is a 33 B‑parameter Japanese transformer released by NII’s Large Language Model R&D Center, trained with pre‑/mid‑training followed by supervised fine‑tuning and DPO (no RL), and usable via llama.cpp with a custom fork.
 * [LFM2.5-1.2B-JP-202606-GGUF](https://huggingface.co/LiquidAI/LFM2.5-1.2B-JP-202606-GGUF) - 📥 8k / ⭐ 32 / Hybrid LFM2 models from Liquid AI, such as the 1.2 B Japanese GGUF version, deliver high‑quality, fast, and memory‑efficient edge AI for on‑device deployment and can be run locally with llama.cpp via the Hugging Face repo.
