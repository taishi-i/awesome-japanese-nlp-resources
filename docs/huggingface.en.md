## Models
### text-generation
 * [japanese-gpt-neox-small](https://huggingface.co/rinna/japanese-gpt-neox-small) - 📥 299k / ⭐ 15 / A 12‑layer, 768‑hidden Japanese GPT‑NeoX model trained on CC‑100, C4, and Wikipedia, compatible with Huggingface, with an optional toy prefix‑tuning weight that forces each sentence to end with a smiling‑face emoji.
 * [gpt-neox-japanese-2.7b](https://huggingface.co/abeja/gpt-neox-japanese-2.7b) - 📥 98k / ⭐ 59 / A 2.7‑B‑parameter Japanese GPT‑NeoX model trained on Japanese CC‑100 and OSCAR by ABEJA Inc, usable via Hugging Face Transformers pipelines or PyTorch and released under the MIT license.
 * [llm-jp-4-8b-thinking](https://huggingface.co/llm-jp/llm-jp-4-8b-thinking) - 📥 51k / ⭐ 42 / Provides the 8 B‑parameter LLM‑jp‑4‑8b‑thinking Japanese language model from NII, trained with pre‑/mid‑training and aligned via SFT/DPO, ready to use with torch‑transformers and detailed cookbook instructions.
 * [llm-jp-3-150m](https://huggingface.co/llm-jp/llm-jp-3-150m) - 📥 50k / ⭐ 8 / LLM‑jp‑3‑150m—a 150‑M‑parameter Japanese language model from the National Institute of Informatics’ LLM R&D Center—is distributed in Hugging Face Transformers format, requiring torch ≥ 2.3.0, transformers ≥ 4.40.1, accelerate ≥ 0.29.3, flash‑attn ≥ 2.5.8, and was pretrained on Japanese Wikipedia, Common Crawl, WARP/PDF, WARP/HTML, and Kaken data using a unigram byte‑fallback tokenizer.
 * [llm-jp-4-32b-a3b-thinking](https://huggingface.co/llm-jp/llm-jp-4-32b-a3b-thinking) - 📥 45k / ⭐ 36 / A 32‑billion‑parameter Japanese transformer LLM (llm‑jp‑4‑32b‑a3b‑thinking) from the National Institute of Informatics, pre‑trained and aligned via supervised fine‑tuning and direct preference optimization—no reinforcement learning—using a unigram byte‑fallback tokenizer.
 * [NVIDIA-Nemotron-Nano-9B-v2-Japanese](https://huggingface.co/nvidia/NVIDIA-Nemotron-Nano-9B-v2-Japanese) - 📥 32k / ⭐ 139 / A 9‑billion‑parameter Japanese‑optimized LLM, NVIDIA Nemotron‑Nano‑9B‑v2‑Japanese, trained on data up to September 2024 with a hybrid Mamba‑2/MLP/4‑layer‑attention architecture, fine‑tuned on the Nemotron‑Personas‑Japan tool‑calling dataset, that optionally generates a controllable reasoning trace before producing a final answer and is available for commercial use.
 * [Llama-3.3-Swallow-70B-Instruct-v0.4](https://huggingface.co/tokyotech-llm/Llama-3.3-Swallow-70B-Instruct-v0.4) - 📥 24k / ⭐ 13 / Llama 3.3 Swallow is a 70‑Billion‑parameter Japanese‑enhanced large language model built by continual pre‑training and instruction‑tuned fine‑training on Meta’s Llama 3.3, with multiple released variants (e.g., v0.4) available on Hugging Face and the Swallow website.
 * [open-calm-3b](https://huggingface.co/cyberagent/open-calm-3b) - 📥 20k / ⭐ 21 / OpenCALM is a suite of decoder‑only Japanese transformer language models (160 M–6.8 B params) released by CyberAgent, Inc. under CC‑BY‑SA 4.0, trained on Japanese Wikipedia and Common Crawl, and usable via Hugging Face’s torch‑transformers.
 * [LFM2.5-1.2B-JP-202606](https://huggingface.co/LiquidAI/LFM2.5-1.2B-JP-202606) - 📥 18k / ⭐ 63 / LFM 2.5‑1.2B‑JP‑202606 is a high‑performance, general‑purpose Japanese chat model that outperforms comparable sub‑2 B models in knowledge, instruction following, math, code, and tool use, making it ideal for developers building culturally nuanced Japanese applications.
 * [karasu-1.1B](https://huggingface.co/lightblue/karasu-1.1B) - 📥 12k / ⭐ 7 / Pretrained TinyLlama in Japanese (≈50 k steps) built on ~3 B OSCAR/mC4 tokens, usable via HuggingFace Transformers or VLLM, created by Peter Devine, Sho Higuchi, Yuuki Yamanaka, Atom Sonoda, Shunichi Taniguchi, Tomioka Wataru, and Renju Aoki.

 * [sarashina2.2-3b-instruct-v0.1](https://huggingface.co/sbintuitions/sarashina2.2-3b-instruct-v0.1) - 📥 12k / ⭐ 39 / Offers an autoregressive Japanese language model (sarashina2.2‑3B‑instruct‑v0.1) from SB Intuitions, benchmarked against other models, with example usage scripts and a note that safety training is limited.
 * [llm-jp-3-1.8b](https://huggingface.co/llm-jp/llm-jp-3-1.8b) - 📥 11k / ⭐ 17 / A collection of Japanese large‑language models (1.8 b to 172 b beta1, with instruct variants) from NII’s R&D Center, packaged in Hugging Face Transformers format and pretrained on a mix of Japanese, English, and Web corpora totalling >1 trillion tokens, requiring torch ≥ 2.3, transformers ≥ 4.40, accelerate ≥ 0.29, and flash‑attn ≥ 2.5.
