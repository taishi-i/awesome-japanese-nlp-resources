## Models
### text-generation
 * [japanese-gpt-neox-small](https://huggingface.co/rinna/japanese-gpt-neox-small) - 📥 357k / ⭐ 15 / A 12‑layer, 768‑hidden Japanese GPT‑NeoX model trained on CC‑100, C4, and Wikipedia, compatible with Huggingface, with an optional toy prefix‑tuning weight that forces each sentence to end with a smiling‑face emoji.
 * [NVIDIA-Nemotron-Nano-9B-v2-Japanese](https://huggingface.co/nvidia/NVIDIA-Nemotron-Nano-9B-v2-Japanese) - 📥 187k / ⭐ 138 / A 9‑billion‑parameter Japanese‑optimized LLM, NVIDIA Nemotron‑Nano‑9B‑v2‑Japanese, trained on data up to September 2024 with a hybrid Mamba‑2/MLP/4‑layer‑attention architecture, fine‑tuned on the Nemotron‑Personas‑Japan tool‑calling dataset, that optionally generates a controllable reasoning trace before producing a final answer and is available for commercial use.
 * [open-calm-3b](https://huggingface.co/cyberagent/open-calm-3b) - 📥 128k / ⭐ 21 / OpenCALM is a suite of decoder‑only Japanese transformer language models (160 M–6.8 B params) released by CyberAgent, Inc. under CC‑BY‑SA 4.0, trained on Japanese Wikipedia and Common Crawl, and usable via Hugging Face’s torch‑transformers.
 * [gpt-neox-japanese-2.7b](https://huggingface.co/abeja/gpt-neox-japanese-2.7b) - 📥 126k / ⭐ 59 / A 2.7‑B‑parameter Japanese GPT‑NeoX model trained on Japanese CC‑100 and OSCAR by ABEJA Inc, usable via Hugging Face Transformers pipelines or PyTorch and released under the MIT license.
 * [llm-jp-4-8b-thinking](https://huggingface.co/llm-jp/llm-jp-4-8b-thinking) - 📥 84k / ⭐ 42 / Provides the 8 B‑parameter LLM‑jp‑4‑8b‑thinking Japanese language model from NII, trained with pre‑/mid‑training and aligned via SFT/DPO, ready to use with torch‑transformers and detailed cookbook instructions.
 * [llm-jp-3-150m](https://huggingface.co/llm-jp/llm-jp-3-150m) - 📥 52k / ⭐ 7 / LLM‑jp‑3‑150m—a 150‑M‑parameter Japanese language model from the National Institute of Informatics’ LLM R&D Center—is distributed in Hugging Face Transformers format, requiring torch ≥ 2.3.0, transformers ≥ 4.40.1, accelerate ≥ 0.29.3, flash‑attn ≥ 2.5.8, and was pretrained on Japanese Wikipedia, Common Crawl, WARP/PDF, WARP/HTML, and Kaken data using a unigram byte‑fallback tokenizer.
 * [llm-jp-4-32b-a3b-thinking](https://huggingface.co/llm-jp/llm-jp-4-32b-a3b-thinking) - 📥 32k / ⭐ 35 / A 32‑billion‑parameter Japanese transformer LLM (llm‑jp‑4‑32b‑a3b‑thinking) from the National Institute of Informatics, pre‑trained and aligned via supervised fine‑tuning and direct preference optimization—no reinforcement learning—using a unigram byte‑fallback tokenizer.
 * [Llama-3.3-Swallow-70B-Instruct-v0.4](https://huggingface.co/tokyotech-llm/Llama-3.3-Swallow-70B-Instruct-v0.4) - 📥 23k / ⭐ 13 / Llama 3.3 Swallow is a 70‑Billion‑parameter Japanese‑enhanced large language model built by continual pre‑training and instruction‑tuned fine‑training on Meta’s Llama 3.3, with multiple released variants (e.g., v0.4) available on Hugging Face and the Swallow website.
 * [llm-jp-4-8b-instruct](https://huggingface.co/llm-jp/llm-jp-4-8b-instruct) - 📥 22k / ⭐ 10 / llm‑jp‑4‑8b‑instruct is a 4.1 B‑parameter Japanese LLM from NII’s LLM‑jp‑4 series, pretrained on large corpora and then fine‑tuned solely with supervised instruction data (no DPO/REINFORCE) and accompanied by cookbook‑style usage guides and a byte‑fallback unigram tokenizer.
 * [shisa-gamma-7b-v1](https://huggingface.co/augmxnt/shisa-gamma-7b-v1) - 📥 20k / ⭐ 18 / Fine‑tuned the Japanese Stable LM Base Gamma 7B with Shisa 7B data, achieving strong results on the JA MT‑Bench.
 * [Llama-3.1-Swallow-8B-Instruct-v0.3](https://huggingface.co/tokyotech-llm/Llama-3.1-Swallow-8B-Instruct-v0.3) - 📥 14k / ⭐ 24 / Llama 3.1 Swallow is a Japanese‑enhanced series of 8B/70B Llama 3.1 models, trained via continual pre‑training and Japanese‑specific instruction fine‑tuning, with the latest 8B‑Instruct‑v0.3 setting state‑of‑the‑art results on Japanese MT‑Bench.
 * [karasu-1.1B](https://huggingface.co/lightblue/karasu-1.1B) - 📥 12k / ⭐ 7 / Pretrained TinyLlama in Japanese (≈50 k steps) built on ~3 B OSCAR/mC4 tokens, usable via HuggingFace Transformers or VLLM, created by Peter Devine, Sho Higuchi, Yuuki Yamanaka, Atom Sonoda, Shunichi Taniguchi, Tomioka Wataru, and Renju Aoki.
 * [LFM2.5-1.2B-JP-202606](https://huggingface.co/LiquidAI/LFM2.5-1.2B-JP-202606) - 📥 12k / ⭐ 63 / LFM 2.5‑1.2B‑JP‑202606 is a high‑performance, general‑purpose Japanese chat model that outperforms comparable sub‑2 B models in knowledge, instruction following, math, code, and tool use, making it ideal for developers building culturally nuanced Japanese applications.
 * [Llama-3-Swallow-8B-Instruct-v0.1](https://huggingface.co/tokyotech-llm/Llama-3-Swallow-8B-Instruct-v0.1) - 📥 10k / ⭐ 21 / Llama3 Swallow is a Japanese‑enhanced Meta Llama 3 family released July 1 2024, offering 8B and 70B variants in Instruct and chat forms fine‑tuned with SFT and Chat Vector on Megatron‑LM, and benchmarked on key Japanese NLP tasks.
 * [Llama-3-ELYZA-JP-8B](https://huggingface.co/elyza/Llama-3-ELYZA-JP-8B) - 📥 9k / ⭐ 148 / Llama‑3‑ELYZA‑JP‑8B is a Japanese‑enhanced, 8‑billion‑parameter Llama 3 model by ELYZA, fine‑tuned for Japanese on Meta‑Llama‑3‑8B‑Instruct.
 * [Llama-3-70B-japanese-suzume-vector-v0.1](https://huggingface.co/mmnga/Llama-3-70B-japanese-suzume-vector-v0.1) - 📥 8k / ⭐ 4 / Experimental Japanese model created by extracting differences between lightblue/suzume‑llama‑3‑8B‑japanese and Meta‑Llama‑3‑8B‑Instruct using a chat‑vector approach, upsampled and applied to Meta‑Llama‑3‑70B‑Instruct, showing little change and planning future scaling.
 * [japanese-gpt2-medium](https://huggingface.co/rinna/japanese-gpt2-medium) - 📥 7k / ⭐ 85 / Rinna’s 24‑layer, 1024‑hidden Japanese GPT‑2‑medium model, trained on CC‑100 and Wikipedia with SentencePiece tokenization, is available in the rinna/japanese‑pretrained‑models repo (MIT‑licensed, released April 7 2021, updated 25 Aug 2021).
 * [llm-jp-3-1.8b](https://huggingface.co/llm-jp/llm-jp-3-1.8b) - 📥 7k / ⭐ 17 / A collection of Japanese large‑language models (1.8 b to 172 b beta1, with instruct variants) from NII’s R&D Center, packaged in Hugging Face Transformers format and pretrained on a mix of Japanese, English, and Web corpora totalling >1 trillion tokens, requiring torch ≥ 2.3, transformers ≥ 4.40, accelerate ≥ 0.29, and flash‑attn ≥ 2.5.
 * [japanese-stablelm-instruct-gamma-7B-GGUF](https://huggingface.co/TheBloke/japanese-stablelm-instruct-gamma-7B-GGUF) - 📥 7k / ⭐ 10 / Repository provides GGUF‑formatted, quantised model files for Stability AI’s Japanese StableLM Instruct Gamma 7B, created with Massed Compute hardware and part of TheBloke’s a16z‑funded LLM work.
