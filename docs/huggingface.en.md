This page lists Japanese NLP-specific models and datasets available on Hugging Face. Currently, it includes 221 models and 155 datasets.

## Models
### text-generation
 * [japanese-gpt-neox-small](https://huggingface.co/rinna/japanese-gpt-neox-small) - 📥 542k / ⭐ 15 / A 12‑layer, 768‑hidden Japanese GPT‑NeoX model trained on CC‑100, C4, and Wikipedia, compatible with Huggingface, with an optional toy prefix‑tuning weight that forces each sentence to end with a smiling‑face emoji.
 * [Llama-3.1-Swallow-8B-Instruct-v0.5](https://huggingface.co/tokyotech-llm/Llama-3.1-Swallow-8B-Instruct-v0.5) - 📥 105k / ⭐ 19 / Llama 3.1 Swallow is a set of 8‑B and 70‑B models that continue pre‑training Meta’s Llama 3.1 to boost Japanese language performance, then instruction‑fine‑tune on synthetic Japanese data—providing multiple released variants with improved conversational behavior comparable to gemma‑3‑27b‑it.
 * [llm-jp-3-150m](https://huggingface.co/llm-jp/llm-jp-3-150m) - 📥 89k / ⭐ 8 / LLM‑jp‑3‑150m—a 150‑M‑parameter Japanese language model from the National Institute of Informatics’ LLM R&D Center—is distributed in Hugging Face Transformers format, requiring torch ≥ 2.3.0, transformers ≥ 4.40.1, accelerate ≥ 0.29.3, flash‑attn ≥ 2.5.8, and was pretrained on Japanese Wikipedia, Common Crawl, WARP/PDF, WARP/HTML, and Kaken data using a unigram byte‑fallback tokenizer.
 * [sarashina2.2-0.5b-instruct-v0.1](https://huggingface.co/sbintuitions/sarashina2.2-0.5b-instruct-v0.1) - 📥 81k / ⭐ 16 / SB Intuitions’ Sarashina2.2‑0.5B instruct v0.1 is a 0.5‑billion‑parameter Japanese autoregressive model that performs well on Japanese and English MT benchmarks and is ready to load via torch‑transformers.
 * [gpt-neox-japanese-2.7b](https://huggingface.co/abeja/gpt-neox-japanese-2.7b) - 📥 80k / ⭐ 59 / A 2.7‑B‑parameter Japanese GPT‑NeoX model trained on Japanese CC‑100 and OSCAR by ABEJA Inc, usable via Hugging Face Transformers pipelines or PyTorch and released under the MIT license.
 * [Qwen3-Swallow-32B-RL-v0.2-AWQ-INT4](https://huggingface.co/tokyotech-llm/Qwen3-Swallow-32B-RL-v0.2-AWQ-INT4) - 📥 73k / ⭐ 2 / Bilingual Japanese‑English LLMs (30B‑A3B / 32B) in Qwen3‑Swallow v0.2 were trained via CPT, SFT, and RLVR to preserve math and coding performance, boost reasoning, and are released with several quantised versions on Hugging Face.
 * [open-calm-3b](https://huggingface.co/cyberagent/open-calm-3b) - 📥 45k / ⭐ 21 / OpenCALM is a suite of decoder‑only Japanese transformer language models (160 M–6.8 B params) released by CyberAgent, Inc. under CC‑BY‑SA 4.0, trained on Japanese Wikipedia and Common Crawl, and usable via Hugging Face’s torch‑transformers.
 * [LFM2.5-1.2B-JP-202606](https://huggingface.co/LiquidAI/LFM2.5-1.2B-JP-202606) - 📥 20k / ⭐ 76 / LFM 2.5‑1.2B‑JP‑202606 is a high‑performance, general‑purpose Japanese chat model that outperforms comparable sub‑2 B models in knowledge, instruction following, math, code, and tool use, making it ideal for developers building culturally nuanced Japanese applications.
 * [llm-jp-4-33b-thinking](https://huggingface.co/llm-jp/llm-jp-4-33b-thinking) - 📥 13k / ⭐ 39 / Repository hosting the llm‑jp‑4‑33b‑thinking 33 B‑parameter transformer model from NII’s LLM research center, fine‑tuned via supervised and preference optimization and supported by practical usage guides.
 * [Llama-3-Swallow-8B-Instruct-v0.1](https://huggingface.co/tokyotech-llm/Llama-3-Swallow-8B-Instruct-v0.1) - 📥 9k / ⭐ 21 / Llama3 Swallow is a Japanese‑enhanced Meta Llama 3 family released July 1 2024, offering 8B and 70B variants in Instruct and chat forms fine‑tuned with SFT and Chat Vector on Megatron‑LM, and benchmarked on key Japanese NLP tasks.
 * [LFM2.5-1.2B-JP-202606-ONNX](https://huggingface.co/LiquidAI/LFM2.5-1.2B-JP-202606-ONNX) - 📥 9k / ⭐ 6 / Exports the Japanese LFM2.5‑1.2B model to ONNX for cross‑platform inference with ONNX Runtime, Transformers.js, and WebGPU, offering multiple precision variants (FP32, FP16, INT4/FP16 mix) and a recommended WebGPU‑friendly INT4+FP16 format.
 * [Llama-3-70B-japanese-suzume-vector-v0.1](https://huggingface.co/mmnga/Llama-3-70B-japanese-suzume-vector-v0.1) - 📥 8k / ⭐ 4 / Experimental Japanese model created by extracting differences between lightblue/suzume‑llama‑3‑8B‑japanese and Meta‑Llama‑3‑8B‑Instruct using a chat‑vector approach, upsampled and applied to Meta‑Llama‑3‑70B‑Instruct, showing little change and planning future scaling.
 * [shisa-gamma-7b-v1](https://huggingface.co/augmxnt/shisa-gamma-7b-v1) - 📥 8k / ⭐ 18 / Fine‑tuned the Japanese Stable LM Base Gamma 7B with Shisa 7B data, achieving strong results on the JA MT‑Bench.
 * [Qwen3-Swallow-32B-RL-v0.2](https://huggingface.co/tokyotech-llm/Qwen3-Swallow-32B-RL-v0.2) - 📥 8k / ⭐ 3 / Qwen3‑Swallow v0.2 delivers 30‑B and 32‑B bilingual Japanese‑English LLMs trained with CPT, SFT, and RLVR that enhance Japanese accuracy, translation, math, and coding to match or surpass the original Qwen3, offering nine models (CPT, SFT, RL) and AWQ‑quantized versions, with GPT‑OSS‑Swallow also released.
 * [llm-jp-3-1.8b](https://huggingface.co/llm-jp/llm-jp-3-1.8b) - 📥 8k / ⭐ 17 / A collection of Japanese large‑language models (1.8 b to 172 b beta1, with instruct variants) from NII’s R&D Center, packaged in Hugging Face Transformers format and pretrained on a mix of Japanese, English, and Web corpora totalling >1 trillion tokens, requiring torch ≥ 2.3, transformers ≥ 4.40, accelerate ≥ 0.29, and flash‑attn ≥ 2.5.
 * [llm-jp-4-8b-instruct](https://huggingface.co/llm-jp/llm-jp-4-8b-instruct) - 📥 7k / ⭐ 12 / llm‑jp‑4‑8b‑instruct is a 4.1 B‑parameter Japanese LLM from NII’s LLM‑jp‑4 series, pretrained on large corpora and then fine‑tuned solely with supervised instruction data (no DPO/REINFORCE) and accompanied by cookbook‑style usage guides and a byte‑fallback unigram tokenizer.
 * [Llama-3-ELYZA-JP-8B](https://huggingface.co/elyza/Llama-3-ELYZA-JP-8B) - 📥 6k / ⭐ 151 / Llama‑3‑ELYZA‑JP‑8B is a Japanese‑enhanced, 8‑billion‑parameter Llama 3 model by ELYZA, fine‑tuned for Japanese on Meta‑Llama‑3‑8B‑Instruct.
 * [sarashina2.2-3b-instruct-v0.1](https://huggingface.co/sbintuitions/sarashina2.2-3b-instruct-v0.1) - 📥 6k / ⭐ 39 / Offers an autoregressive Japanese language model (sarashina2.2‑3B‑instruct‑v0.1) from SB Intuitions, benchmarked against other models, with example usage scripts and a note that safety training is limited.
 * [asmr-qwen3.5-9b-zh-cn-echo-mtp-gguf-v0.1](https://huggingface.co/mmis1000/asmr-qwen3.5-9b-zh-cn-echo-mtp-gguf-v0.1) - 📥 6k / ⭐ 2 / Fine‑tuned Qwen3.5 MTP in GGUF format that translates Japanese ASMR transcriptions into Simplified Chinese while echoing the source text, applying domain glossaries, and preserving emotion with several quantized versions (q4_k_m, q6_k, q8_0, bf16).
 * [japanese-stablelm-instruct-gamma-7B-GGUF](https://huggingface.co/TheBloke/japanese-stablelm-instruct-gamma-7B-GGUF) - 📥 5k / ⭐ 10 / Repository provides GGUF‑formatted, quantised model files for Stability AI’s Japanese StableLM Instruct Gamma 7B, created with Massed Compute hardware and part of TheBloke’s a16z‑funded LLM work.
 * [llm-jp-4-8b-thinking](https://huggingface.co/llm-jp/llm-jp-4-8b-thinking) - 📥 5k / ⭐ 48 / Provides the 8 B‑parameter LLM‑jp‑4‑8b‑thinking Japanese language model from NII, trained with pre‑/mid‑training and aligned via SFT/DPO, ready to use with torch‑transformers and detailed cookbook instructions.
