This page lists Japanese NLP-specific models and datasets available on Hugging Face. Currently, it includes 183 models and 132 datasets.

## Models
### text-generation
 * [japanese-gpt-neox-small](https://huggingface.co/rinna/japanese-gpt-neox-small) - 📥 242k / ⭐ 15 / A 12‑layer, 768‑hidden Japanese GPT‑NeoX model trained on CC‑100, C4, and Wikipedia, compatible with Huggingface, with an optional toy prefix‑tuning weight that forces each sentence to end with a smiling‑face emoji.
 * [gpt-neox-japanese-2.7b](https://huggingface.co/abeja/gpt-neox-japanese-2.7b) - 📥 76k / ⭐ 59 / A 2.7‑B‑parameter Japanese GPT‑NeoX model trained on Japanese CC‑100 and OSCAR by ABEJA Inc, usable via Hugging Face Transformers pipelines or PyTorch and released under the MIT license.
 * [llm-jp-3-150m](https://huggingface.co/llm-jp/llm-jp-3-150m) - 📥 29k / ⭐ 8 / LLM‑jp‑3‑150m—a 150‑M‑parameter Japanese language model from the National Institute of Informatics’ LLM R&D Center—is distributed in Hugging Face Transformers format, requiring torch ≥ 2.3.0, transformers ≥ 4.40.1, accelerate ≥ 0.29.3, flash‑attn ≥ 2.5.8, and was pretrained on Japanese Wikipedia, Common Crawl, WARP/PDF, WARP/HTML, and Kaken data using a unigram byte‑fallback tokenizer.
 * [llm-jp-4-8b-thinking](https://huggingface.co/llm-jp/llm-jp-4-8b-thinking) - 📥 21k / ⭐ 43 / Provides the 8 B‑parameter LLM‑jp‑4‑8b‑thinking Japanese language model from NII, trained with pre‑/mid‑training and aligned via SFT/DPO, ready to use with torch‑transformers and detailed cookbook instructions.
 * [LFM2.5-1.2B-JP-202606](https://huggingface.co/LiquidAI/LFM2.5-1.2B-JP-202606) - 📥 20k / ⭐ 65 / LFM 2.5‑1.2B‑JP‑202606 is a high‑performance, general‑purpose Japanese chat model that outperforms comparable sub‑2 B models in knowledge, instruction following, math, code, and tool use, making it ideal for developers building culturally nuanced Japanese applications.
 * [LFM2.5-1.2B-JP-202606-ONNX](https://huggingface.co/LiquidAI/LFM2.5-1.2B-JP-202606-ONNX) - 📥 20k / ⭐ 1 / Exports the Japanese LFM2.5‑1.2B model to ONNX for cross‑platform inference with ONNX Runtime, Transformers.js, and WebGPU, offering multiple precision variants (FP32, FP16, INT4/FP16 mix) and a recommended WebGPU‑friendly INT4+FP16 format.
 * [llm-jp-4-32b-a3b-thinking](https://huggingface.co/llm-jp/llm-jp-4-32b-a3b-thinking) - 📥 16k / ⭐ 36 / A 32‑billion‑parameter Japanese transformer LLM (llm‑jp‑4‑32b‑a3b‑thinking) from the National Institute of Informatics, pre‑trained and aligned via supervised fine‑tuning and direct preference optimization—no reinforcement learning—using a unigram byte‑fallback tokenizer.
 * [sarashina2.2-3b-instruct-v0.1](https://huggingface.co/sbintuitions/sarashina2.2-3b-instruct-v0.1) - 📥 15k / ⭐ 39 / Offers an autoregressive Japanese language model (sarashina2.2‑3B‑instruct‑v0.1) from SB Intuitions, benchmarked against other models, with example usage scripts and a note that safety training is limited.
 * [Llama-3.1-Swallow-8B-Instruct-v0.5](https://huggingface.co/tokyotech-llm/Llama-3.1-Swallow-8B-Instruct-v0.5) - 📥 14k / ⭐ 19 / Llama 3.1 Swallow is a set of 8‑B and 70‑B models that continue pre‑training Meta’s Llama 3.1 to boost Japanese language performance, then instruction‑fine‑tune on synthetic Japanese data—providing multiple released variants with improved conversational behavior comparable to gemma‑3‑27b‑it.
 * [shisa-gamma-7b-v1](https://huggingface.co/augmxnt/shisa-gamma-7b-v1) - 📥 12k / ⭐ 18 / Fine‑tuned the Japanese Stable LM Base Gamma 7B with Shisa 7B data, achieving strong results on the JA MT‑Bench.
 * [llm-jp-4-8b-instruct](https://huggingface.co/llm-jp/llm-jp-4-8b-instruct) - 📥 11k / ⭐ 10 / llm‑jp‑4‑8b‑instruct is a 4.1 B‑parameter Japanese LLM from NII’s LLM‑jp‑4 series, pretrained on large corpora and then fine‑tuned solely with supervised instruction data (no DPO/REINFORCE) and accompanied by cookbook‑style usage guides and a byte‑fallback unigram tokenizer.
 * [Qwen3-Swallow-32B-RL-v0.2](https://huggingface.co/tokyotech-llm/Qwen3-Swallow-32B-RL-v0.2) - 📥 10k / ⭐ 3 / Qwen3‑Swallow v0.2 delivers 30‑B and 32‑B bilingual Japanese‑English LLMs trained with CPT, SFT, and RLVR that enhance Japanese accuracy, translation, math, and coding to match or surpass the original Qwen3, offering nine models (CPT, SFT, RL) and AWQ‑quantized versions, with GPT‑OSS‑Swallow also released.
 * [japanese-gpt2-medium](https://huggingface.co/rinna/japanese-gpt2-medium) - 📥 10k / ⭐ 85 / Rinna’s 24‑layer, 1024‑hidden Japanese GPT‑2‑medium model, trained on CC‑100 and Wikipedia with SentencePiece tokenization, is available in the rinna/japanese‑pretrained‑models repo (MIT‑licensed, released April 7 2021, updated 25 Aug 2021).
